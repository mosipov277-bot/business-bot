# 🤖 Business Bot — платформа AI-ботов для малого бизнеса

Один Telegram-бот, внутри которого живут **боты разных компаний**.
Владелец бизнеса заполняет анкету за 2 минуты → получает свою ссылку →
клиенты пишут по этой ссылке → AI отвечает + принимает онлайн-записи.

---

## 🗂 Файлы в этом проекте

| Файл              | Что это                                      |
|-------------------|-----------------------------------------------|
| `bot.py`          | Весь бэкенд: Telegram-бот + AI + HTTP API     |
| `index.html`      | Мини-приложение (WebApp) — открывается в Telegram |
| `requirements.txt`| Python-зависимости                             |
| `Procfile`        | Команда запуска для Railway                    |
| `runtime.txt`     | Версия Python для Railway                      |

## 🚀 ПОЛНАЯ УСТАНОВКА С НУЛЯ (всё бесплатно)

### Шаг 0 — Что подготовить заранее
1. Токен бота — напиши **@BotFather** → `/newbot` → следуй инструкциям → скопируй токен
2. Ключ YandexGPT:
   - Зайди на **console.cloud.yandex.ru** → создай каталог
   - Скопируй **Folder ID** (виден в адресной строке, формат `b1g...`)
   - Слева: **IAM → Сервисные аккаунты → Создать**
   - Роль: `ai.languageModels.user`
   - Открой аккаунт → **API-ключи → Создать** → скопируй ключ (`AQVN...`)
3. Свой Telegram ID — напиши **@userinfobot**, он пришлёт твой ID числом

---

### Шаг 1 — GitHub
1. Зайди на **github.com** → зарегистрируйся (если ещё нет)
2. **New repository** → имя `business-bot` → Public → Create
3. **Add file → Upload files** → загрузи ВСЕ 5 файлов из этой папки
4. **Commit changes**

---

### Шаг 2 — Vercel (хостинг WebApp)
1. Зайди на **vercel.com** → **Continue with GitHub**
2. **Add New → Project** → выбери репозиторий `business-bot` → **Import**
3. Ничего не меняй → **Deploy**
4. Через 30 секунд получишь ссылку вида:
   ```
   https://business-bot-xxxx.vercel.app
   ```
5. **Сохрани эту ссылку** — она понадобится в Шаге 4

---

### Шаг 3 — Railway (хостинг бота)
1. Зайди на **railway.app** → **Login with GitHub**
2. **New Project → Deploy from GitHub repo** → выбери `business-bot`
3. Дождись первого (возможно неудачного) деплоя — это нормально, переменных ещё нет
4. Открой сервис → вкладка **Variables** → **Raw Editor** → вставь:
   ```
   BOT_TOKEN=токен_от_botfather
   YANDEX_API_KEY=AQVN...
   YANDEX_FOLDER_ID=b1g...
   WEBAPP_URL=https://business-bot-xxxx.vercel.app
   ```
   (вставь свою ссылку с Vercel из Шага 2)
5. **Save** — Railway автоматически передеплоит бота
6. Перейди в **Settings → Networking → Generate Domain**
   Получишь ссылку вида:
   ```
   https://business-bot-production-xxxx.up.railway.app
   ```
   **Сохрани её** — это API-адрес бота

---

### Шаг 4 — Связываем WebApp с ботом
Открытый `index.html` содержит строку:
```js
const API = "__BOT_API_URL__";
```

1. На GitHub открой `index.html` → нажми ✏️ (Edit)
2. Нажми `Ctrl+F` (поиск в браузере) → найди `__BOT_API_URL__`
3. Замени на свою ссылку с Railway из Шага 3, например:
   ```js
   const API = "https://business-bot-production-xxxx.up.railway.app";
   ```
4. **Commit changes**

Vercel автоматически передеплоит за ~30 секунд.

---

### Шаг 5 — Кнопка «Меню» в боте
1. Напиши **@BotFather** → `/mybots` → выбери своего бота
2. **Bot Settings → Menu Button → Configure menu button**

   Если такого пункта нет — напиши команду:
   ```
   /setmenubutton
   ```
   выбери бота → введи URL:
   ```
   https://business-bot-xxxx.vercel.app?mode=setup
   ```
   (твоя ссылка с Vercel + `?mode=setup`)
3. Введи текст кнопки: `Меню`

---

### Шаг 6 — Проверка
1. Напиши своему боту `/start`
2. Нажми кнопку **Меню** внизу
3. Заполни анкету → **Создать бота**
4. Бот пришлёт сообщение со ссылкой вида `t.me/твойбот?start=biz_1`
5. Открой эту ссылку в новом чате (можно с другого аккаунта) —
   увидишь приветствие клиента с кнопками «Записаться» / «Спросить AI»

Если всё работает — поздравляю, платформа запущена! 🎉

## 🔧 Если что-то не работает

| Проблема | Решение |
|---|---|
| Railway деплой падает без логов | Проверь что `bot.py` называется именно так (без `(2)` в имени) |
| WebApp открывается белым экраном | Проверь что `__BOT_API_URL__` заменён на реальный Railway URL |
| Кнопка "Создать бота" не реагирует | Открывай WebApp ТОЛЬКО через кнопку «Меню» в боте, не через браузер |
| AI не отвечает / ошибка | Проверь YANDEX_API_KEY и YANDEX_FOLDER_ID в Railway Variables |
| Бот не отвечает вообще | Railway → Deployments → должен быть статус ACTIVE (зелёный) |
